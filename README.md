实验内容及要求
1. 对软件开发过程、软件开发方法、软件开发环境有所掌握并进行基本
实践。
2. 设计并实现一款数据备份软件，以项目组形式推进，每组最多3人。
3. 基于面向对象的软件工程方法学进行项目推进，经历从需求分析、系统设计、编码实现、软件测试的整个软件生命周期。
4. 实验最终成果包括一款基本可用的软件及其对应文档。
5. 软件应包括选定的完整功能，重点考察其正确性、易用性、健壮性。
6. 软件文档应包括：需求分析说明书、系统设计文档、软件测试报告，重点考察其规范性、一致性、可读性。
7. 采用现代化软件开发工具辅助项目开发，包括但不限于：UML建模工具（StarUML），集成开发环境（VSCode、make、gdb），版本控制工具（git），代码检测工具（cpplint），软件测试工具（gtest、valgrind、gprof、perf）。

基本要求

各小组“独立”实现一款数据备份软件（对应基础分总分40分）：

数据备份：将目录树中的文件数据保存到指定位置

数据还原：将目录树中的文件数据恢复到指定位置

扩展要求

文件类型支持（满分10分）：支持特定文件系统的特殊文件（管道/链接/设备等）

元数据支持（满分10分）：支持特定文件系统的文件元数据（属主/时间/权限等）

自定义备份（各3分）：支持筛选需要备份的文件（路径/类型/名字/时间/尺寸/用户）

打包解包（每种算法10分）：将所有备份文件拼接为一个大文件保存

压缩解压（每种算法10分）：通过文件压缩节省备份文件的存储空间

加密解密（每种算法10分）：由用户指定密码，将所有备份文件均加密保存

图形界面（满分10分）：实现友好易用的GUI界面

定时备份（满分10分）：允许用户进行设置，进行周期性定时备份和数据淘汰

开发环境

操作系统选择：Windows

开发语言选择：C++；用户界面可以采用脚本语言或Qt编写。

库的使用：对所有扩展功能，如使用第三方库/程序/代码“直接”实现，对应功能扩展分总分记为原来的50%。

提交资料
以小组为单位：
1. 小组报告文档（需求、设计、测试）
2. 项目答辩PPT
3. 源代码+可执行程序（包含构建脚本，如cmake等）
4. 项目演示视频链接（3分钟以内）

备注：
采用gtest测试框架，完成项目中任一模块的白盒单元测试。测试代码留在项目源代码中。

项目报告中，至少包含两种以上测试类型（单元测试、集成测试、性能测试、稳定性测试等）。

项目报告中，至少包含15个以上测试用例

二、技术与实现约定
- 开发语言：C++17（全部核心业务）；用户界面：Python 3.11 + PySide6（脚本语言，符合"用户界面可以采用脚本语言"的要求）。
- 构建：Makefile（w64devkit g++ 12.1.0）；另提供 cmake 3.30.3 环境（可选）。
- 压缩解压：自研 DEFLATE 算法（LZ77 滑动窗口匹配 + 固定 Huffman 编码，遵循 RFC 1951），不使用 zlib 等第三方库直接实现。
- 打包解包：自研 BKPK 容器格式（固定头 + 条目表 + 数据区）。
- 加密解密：自研流密码（口令 + 随机 IV，KSA/PRGA）。
- 测试：gtest 白盒单元测试（C++ 核心）+ Python unittest + 集成测试脚本；测试用例总数 ≥15，覆盖单元测试与集成测试两类以上。

三、构建与运行
构建：make -j
单元测试：make test（C++ gtest）；make test-py（Python unittest）
运行 CLI：./build/dataguard-cli --version
